# ねこの手ちょいちょい（試作）

年配の人向けのパズルゲームの試作です。1面「まるまる堂のみせさき」のはじめの12ステージが遊べます。

## 遊び方

- ねこの手で毛糸玉を1つ抜くと（1手）、上の玉が1段さがります。
- 同じ色の毛糸玉が横か縦に3つ並ぶと、ねこが巻き取ります。続けてそろうと「れんさ」になります。
- 何もそろわない所は抜けません。ただし、子猫の真下の毛糸玉だけは、そろわなくても抜けます。
- 1回目のタップで、そろう玉が光ります（予告）。同じ玉をもう一度タップすると抜けます。
- 4つ並ぶと「ころころ毛糸玉」（1列ぜんぶ）、5つ以上や曲がった並びだと「ねこパンチ」（まわり3×3）ができます。
- 目標：色の毛糸をN玉・みかん箱をN個（となりで巻くとこわれる）・子猫をN匹下ろす。
- 手の数を使い切るとゲームオーバー。上から落ちてくる玉は毎回ちがうので、運も絡みます。
- お助け：またたび（＋5手）・ねこパンチ・大そうじ（1色ぜんぶ）。動画（広告）は、本人が押して「はい」を選んだときだけ（試作では広告のかわりの画面）。

## 動かし方

```bash
npm install
npm run dev
```

- ルールのテスト：`npm test`
- 本番用の組み立て：`npm run build`（`dist/` に出ます）

## つくり

- `src/engine/rules.ts` … ルールの本体。画面と切り離してあり、同じ種（seed）なら同じ結果になります。
- `src/engine/stages.ts` … 12ステージの設定。
- `src/game/BoardView.ts` … 盤面の絵と動き（PixiJS）。
- `src/art/` … 毛糸玉・みかん箱・子猫・ねこの手の絵（SVG をその場で作る。画像ファイルは使わない）。
- `src/ui/` … 画面（はじめ・地図・遊ぶ・アルバム）。

## 評価の道具

ボット（上手＝2手先まで考える／初心者＝見えている結果で選び、3割は気まぐれ／でたらめ）に遊ばせて測ります。

| 何を測るか | 動かし方 |
|---|---|
| ステージごとのクリア率 | `EVAL_N=80 npx vitest run -t "12ステージ" --silent=false` |
| 使った手の数・れんさ・あと少しで負けた割合 | `FEEL=1 EVAL_N=100 npx vitest run src/engine/feel.test.ts --silent=false` |
| 目標の数と手の数を合わせ直す | `TUNE2=1 EVAL_N=80 npx vitest run src/engine/tune2.test.ts --silent=false` |

開発中だけ `window.__choi`（state / best / cands / tap / render）で、ブラウザから盤面を自動で動かせます（本番の組み立てには入りません）。
